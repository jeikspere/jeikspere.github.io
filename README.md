# Multimedia en HTML

Web estática con imagen responsiva, vídeo con subtítulos y audio.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta (con `index.html` en la raíz).
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y pulsa **Save**.
4. En uno o dos minutos tendrás el enlace: `https://TU-USUARIO.github.io/NOMBRE-REPO/`
